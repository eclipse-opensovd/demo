# Eclipse OpenSOVD Demo Repository

This repository contains demonstration projects for Eclipse OpenSOVD (Open Source Vehicle Diagnostics).

## Available Demos

### [CDA OAuth Demo](cda-oauth/)

A demonstration of Eclipse OpenSOVD's Classic Diagnostic Adapter (CDA) with Google OAuth 2.0 authentication, diagnostic format conversion tools, and ECU simulation capabilities.

This demo was used for the "Diagnostics Reimagined" presentation at OCA 2026.

**→ [View full documentation](cda-oauth/README.md)**
